# CC Relay Licensing

CC Relay is open-source software under the standard MIT License, copyright 2026 Patrik Kelemen.

The root `LICENSE` contains the canonical MIT text. `package.json` and the root package record in `package-lock.json` both use the SPDX identifier `MIT`. The package remains `private: true` only to prevent accidental npm publication; that field does not restrict source-code rights.

> [!important]
> The former CC Relay Source-Available View-Only License 1.0 is superseded for the current repository state. Public documentation must describe the project as open source and MIT licensed.

Contributions accepted into the repository are distributed under the same MIT terms. No contributor license agreement or additional project-specific restriction is currently required. Product names and artwork receive only the rights granted by the MIT License as included project materials; no separate trademark policy has been adopted.

> [!note]
> Historical commits preserve the record of the former licensing decision. The public release commit is the clear transition point to MIT and updates the license file, package metadata, README, contribution guide, and wiki together.
