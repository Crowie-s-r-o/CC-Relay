# Relay Licensing

Relay is publicly readable for security, privacy, and trust inspection because it coordinates developers' authenticated Codex and Claude sessions and stores local task activity. Public readability does not grant permission to use the implementation.

The root `LICENSE` is the custom **Relay Source-Available View-Only License 1.0**, copyright 2026 Patrik Kelemen. It permits only viewing through a repository or service authorized by the copyright holder. It does not permit running, copying, downloading, modifying, distributing, incorporating, deriving another project, or using the code to build a competing or substantially similar product.

> [!important]
> Do not describe Relay as open source while this license applies. Use **source available**, **publicly readable source**, or **view-only source**. Open-source definitions require rights that this license intentionally withholds.

`package.json` uses `SEE LICENSE IN LICENSE`. The README states the restriction near the introduction, scopes development instructions to separately authorized users, and links to the complete license.

> [!warning]
> This is a custom legal instrument and should be reviewed by qualified counsel before public launch, especially for enforceability, governing law, contribution handling, and compatibility with the chosen repository host's terms.
