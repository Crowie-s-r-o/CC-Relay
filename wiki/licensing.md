# CC Relay Licensing

CC Relay is source-available under the standard PolyForm Noncommercial License 1.0.0, copyright 2026 Patrik Kelemen.

The license permits use, modification, creation of derivative works, and redistribution for permitted noncommercial purposes. Commercial or other business use is not granted and requires separate prior written permission from Patrik Kelemen.

The root `LICENSE` contains the canonical PolyForm text plus `Required Notice: Copyright (c) 2026 Patrik Kelemen`. `package.json` and the root package record in `package-lock.json` use the SPDX identifier `PolyForm-Noncommercial-1.0.0`. The package remains `private: true` to prevent accidental npm publication; that field does not define source-code rights.

> [!important]
> PolyForm Noncommercial is a source-available license, not an OSI-approved open-source license. Current public documentation must say source-available and must not describe CC Relay as open source.

All commits at the relicensing point have the same author, so the current tree can be offered under the new terms. Contributions accepted later are distributed under the repository license unless separately agreed.

> [!warning]
> Copies or versions already received under MIT retain that irrevocable MIT grant. Changing the current tree governs newly offered versions but cannot retroactively withdraw rights already granted. Release notes and enforcement claims must preserve that distinction.

> [!note]
> Before accepting third-party code, decide whether a contributor agreement is needed. Without adequate relicensing rights from contributors, Patrik Kelemen may not be able to grant a commercial license covering their contributions alone.
